# Live Wallpaper (Windows 11)

폴더에 넣어 둔 **영상 / GIF / 이미지**로 바탕화면을 움직이는 배경화면으로 바꿔 주고, 일정 시간마다 다음 파일로 넘겨 주는 프로그램입니다.
바탕화면이 다른 창에 가려지면 재생을 멈추고, 일정 시간이 지나면 영상을 메모리에서 내려 리소스를 아낍니다.

## 실행

```
bin\LiveWallpaper.exe
```

- 처음 실행하면 설정 창이 열립니다. **찾아보기...** 로 폴더를 고르고 **확인**을 누르면 바로 시작됩니다.
- 실행 중에는 작업 표시줄 트레이(시계 옆)에 아이콘이 있습니다.
  - 왼쪽 클릭: 설정 창
  - 오른쪽 클릭: 다음/이전 배경화면, 일시정지, 폴더 열기, 종료
- 이미 실행 중일 때 exe를 다시 실행하면 설정 창이 열립니다.
- 종료하면 원래 Windows 배경화면이 다시 보입니다.

## 이전 / 다음, 미리보기

- 설정 창 맨 위의 **◀ 이전 / 일시정지 / 다음 ▶** 버튼으로 슬라이드를 바로 넘깁니다. 트레이 메뉴에도 같은 항목이 있습니다.
- 영상이나 GIF 파일을 설정 창(점선 상자)에 **끌어다 놓으면** 그 파일이 바로 배경화면에서 재생됩니다. 상자를 클릭해서 파일을 고를 수도 있습니다.
  - 미리보기 중에는 슬라이드가 넘어가지 않습니다.
  - **폴더에 추가**: 마음에 들면 배경화면 폴더로 복사해서 재생 목록에 넣습니다.
  - **미리보기 끝내기** (또는 이전/다음): 원래 슬라이드쇼로 돌아갑니다.
  - 폴더가 비어 있어도 미리보기는 됩니다.

## 지원 파일

| 종류 | 확장자 |
|---|---|
| 영상 | mp4, m4v, mov, wmv, avi, mkv, webm, mpg, mpeg, 3gp |
| GIF | gif (애니메이션) |
| 이미지 | jpg, jpeg, png, bmp, webp, tif, tiff |

영상 재생은 Windows 기본 코덱(Media Foundation)을 씁니다. H.264 mp4가 가장 무난합니다.
HEVC(H.265)는 Microsoft Store의 "HEVC 비디오 확장", webm(VP9)은 "VP9 비디오 확장"이 설치돼 있어야 합니다.
재생할 수 없는 파일은 자동으로 건너뜁니다. 영상 소리는 기본으로 꺼져 있습니다.

폴더에 파일을 넣거나 지우면 자동으로 목록에 반영됩니다.

## 설정 항목

| 항목 | 설명 |
|---|---|
| 하위 폴더 포함 | 하위 폴더의 파일도 재생 목록에 넣습니다 |
| 전환 간격 | 초 / 분 / 시간 단위. 바탕화면이 보이는 동안만 시간이 흐릅니다 |
| 셔플 | 무작위 순서 (한 바퀴 동안 같은 파일 반복 없음) |
| 끝까지 재생한 뒤 넘어가기 | 전환 시간이 되어도 영상·GIF 한 바퀴가 끝날 때까지 기다립니다 |
| 페이드 전환 | 다음 파일로 넘어갈 때 겹쳐서 부드럽게 전환 (0 = 바로) |
| 화면 맞춤 | 채우기(잘림) / 맞춤(여백) / 늘이기 |
| 모니터 | 모든 모니터에 같은 파일 / 모니터마다 다른 파일 / 주 모니터만 |
| 소리 | 음소거, 볼륨 |
| 다른 창이 덮으면 멈춤 | 모니터 작업 영역이 지정한 비율(기본 90%) 이상 다른 창에 가려지면 그 모니터만 멈춤 (최대화·전체화면 창 포함) |
| 다른 프로그램을 쓰고 있으면 멈춤 | 바탕화면이 아닌 창에 포커스가 있으면 그 창이 있는 모니터를 멈춤 (더 적극적인 절약) |
| 배터리로 동작 중이면 멈춤 | 노트북에서 전원 연결이 끊기면 멈춤 |
| N초 지속되면 메모리에서 내림 | 멈춘 상태가 이어지면 영상 디코더와 프레임을 해제하고 작은 정지 이미지만 남깁니다. 다시 보이면 멈췄던 위치부터 이어서 재생합니다 |
| Windows 시작 시 자동 실행 | 현재 사용자 시작 프로그램에 등록 |

화면이 잠겨 있을 때는 항상 멈춥니다.

설정 파일과 로그는 `%APPDATA%\LiveWallpaper\` (`settings.ini`, `log.txt`)에 저장됩니다.

## 메모리 / CPU (측정값, 이 PC 기준)

| 상태 | 작업 집합(메모리) |
|---|---|
| 1080p 영상 재생 중 | 약 120 MB, CPU 약 5% (한 코어 기준, 하드웨어 디코딩) |
| 640×360 GIF 재생 중 | 약 70 MB, CPU 약 1.5% |
| 가려져서 멈춘 뒤 메모리 해제 | 약 5–20 MB |

4096×2304를 넘는 초고해상도 H.264 영상은 GPU 디코딩이 안 돼 메모리와 CPU를 크게 씁니다 (4500×3000 영상에서 1 GB 이상).
모니터 해상도에 맞춘 영상을 쓰는 것을 권장합니다.

## 빌드

추가 설치 없이 Windows에 들어 있는 .NET Framework 4.8 C# 컴파일러로 빌드합니다.

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

결과물: `bin\LiveWallpaper.exe`, `bin\LiveWallpaper.exe.config` (두 파일을 함께 두면 다른 폴더로 옮겨도 됩니다)

## 동작 방식

- 바탕화면 아이콘 뒤, 원래 배경화면 앞에 창을 끼워 넣습니다.
  Windows 11 24H2 이후(Progman 아래 WorkerW 구조)와 이전 구조(별도 WorkerW)를 모두 처리합니다.
- 영상은 WPF MediaElement(Media Foundation, GPU 디코딩), GIF는 GDI+로 프레임을 합성해 한 장짜리 비트맵에 그립니다.
- 0.5초마다 보이는 창들의 영역을 모니터별로 샘플링해서 가려진 비율을 계산합니다 (다른 가상 데스크톱의 창, 최소화된 창, 클릭이 통과되는 오버레이 창은 무시).
- 탐색기(Explorer)가 재시작되거나 디스플레이 구성이 바뀌면 자동으로 다시 붙습니다.

## 소스 구성

| 파일 | 역할 |
|---|---|
| `src/Program.cs` | 진입점, 단일 인스턴스 |
| `src/TrayApp.cs` | 트레이 아이콘·메뉴, Explorer 재시작 감지 |
| `src/SettingsForm.cs` | 설정 창 |
| `src/WallpaperController.cs` | 재생 목록, 슬라이드쇼 타이머, 멈춤/메모리 해제 판단 |
| `src/ScreenWallpaper.cs` | 모니터 하나의 배경화면 창, 페이드 전환, 멈춤/해제/재개 |
| `src/MediaLayers.cs` | 영상 / GIF / 이미지 재생기 |
| `src/OcclusionDetector.cs` | 창에 가려졌는지 계산 |
| `src/DesktopHost.cs` | 바탕화면 아이콘 뒤 창 찾기 |
| `src/Playlist.cs` | 폴더 스캔, 순서/셔플 |
| `src/Settings.cs` | 설정 저장, 자동 실행 등록, 로그 |
